SVERIGEATLAS ’74 – iPhone-version

INSTALLERA
1. Packa upp ZIP-filen på datorn.
2. Lägg samtliga appfiler på en webbplats med HTTPS, i samma mapp.
   index.html ska ligga direkt i webbplatsens publicerade mapp.
   Du kan använda ett befintligt webbhotell eller GitHub Pages.
3. Öppna webbplatsens adress i Safari på iPhone.
4. Tryck på Dela (ibland via sidmenyn), sedan Lägg till på hemskärmen.
5. Aktivera Öppna som webbapp om alternativet visas. Tryck Lägg till.
6. Starta med ikonen SverigeAtlas på hemskärmen.

GITHUB PAGES, STEG FÖR STEG
- Skapa ett nytt publikt repository, exempelvis sverige-atlas.
- Välj Add file > Upload files. Ladda upp innehållet i appmappen
  (inte ZIP-filen) och välj Commit changes.
- Gå till Settings > Pages.
- Välj Deploy from a branch, main, / (root), Save.
- Vänta tills GitHub visar webbplatsens adress och öppna den i Safari.
  Webbplatsen och koden blir publikt tillgängliga med detta upplägg.

Att enbart spara HTML-filen i appen Filer på iPhone ger inte denna
installation. Appen behöver först en webbadress. Ingen App Store krävs.

INTERNET OCH SPARANDE
Kartor, gränser, Leaflet och webbtypsnitt hämtas från externa tjänster.
Internet behövs för tillförlitligt spel. Det här är inte en fullständig
offlineapp. Service worker sparar appens egna filer, inte en offlinekarta.
Poäng, frågenummer, flik och norrfilter sparas lokalt på enheten.
En ny fråga genereras vid omstart. Rensad webbplatsdata tar bort poängen.

ÄNDRINGAR I VERSION 2
Alla 290 kommuner är möjliga frågor i kommun- och befolkningsquizet.
Alla 21 län och regioner ingår. Befolkningen är från SCB 2024.
Gotland ingår igen. Sex unika alternativ visas alltid i kommunquizet:
först andra kommuner i samma län, sedan slumpade kommuner från övriga
Sverige om länet har färre än sex kommuner. Gotland får fem alternativ
från övriga Sverige, Blekinge ett. Kartpunkter ligger inom respektive
kommunpolygon; punkterna behöver inte vara centralorter.
Norrfiltret styr frågepunkten (latitud minst 59,55), inte utfyllnadsalternativ.

UPPDATERA
Ersätt filerna på din webbplats med samtliga filer i detta paket.
Stäng appen och öppna den på nytt med internetanslutning.

KONTROLL
Alla 290 kommunkoder har matchats mot SCB. Befolkningen per län har
kontrollerats mot summan av länets kommuner. Alla kartpunkter ligger
inom den tillhörande kommunpolygonen. Alternativlogiken kontrolleras
för varje kommun, inklusive Gotland och Blekinge.
Inte provkörd på en fysisk iPhone.
